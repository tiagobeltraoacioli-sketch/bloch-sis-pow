# GIP Editors

GIP editors review Pull Requests to the `gips/` directory for structural completeness (template adherence, required fields, basic readability).

Editors do NOT approve or reject proposals on technical merit — that happens through community discussion in GitHub Issues and the GIP's own tracking thread.

## Becoming an editor

Editors are added by rough consensus of existing editors, typically after sustained, high-quality GIP reviewing over several months. Open a GitHub Issue to propose yourself or a peer.
