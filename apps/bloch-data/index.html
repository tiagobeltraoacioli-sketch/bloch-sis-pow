A CONTRACT WORTH BUILDING ON

From a txid to a complete record.

The target transaction interface returns the fields an integrator needs to reconcile a transfer and follow its status.

  • Canonical inputs and outputs with native amounts
  • Block height, slot and confirmation progress
  • Explicit inclusion, finality and reorganization status
  • Network identity and source provenance

03 / TRUST MODEL

Useful data needs visible boundaries.

A data service should show what the network observed, how the index derived it, and which claims still need independent proof.

01Chain identity

Bind every record to the expected network, chain and genesis.

02Canonicality

Expose reorganization and replay behavior instead of silently replacing history.

03Finality evidence

Separate confirmations from finality; never treat a single node claim as independent proof.

04Operational quality

Measure index freshness, event integrity, availability and recovery time before service commitments.
