# Bloch Ops

Static operations portal for `ops-blochinc.xyz`. It distinguishes published Genesis-4 network entry points and operator guides from planned managed APIs and unactivated delegation.

The portal has dedicated `/rpc/`, `/validators/`, `/wallets/` and `/pq-shield/` pages. The wallet page distributes Genesis-4 SDK 0.1.6, including local wallet creation and recovery, signed transfer construction with byte-correlation checks at broadcast, complete included receipt lookup, explicitly unresolved node-status observation after an archival 404, comparison of successive transaction observations, and exact output matching for deposit reconciliation. It also provides a read-only transaction receipt inspector. The page does not accept a mnemonic or sign in the browser. The validator page uses the live `getvalidatoradmission` response to describe funded admission and publishes a versioned operator onboarding worksheet; the full mainnet exit and withdrawal cycle still requires qualification. Delegation remains inactive.

The PQ Shield section describes the repository's non-custodial Bitcoin reference API. Its local positive anchor check uses a disposable public test seed to verify commitment bytes, signature acceptance, tamper rejection, and serialized-anchor acceptance against the local Rust service. It does not claim a deployed customer service, chain-native PQ authorization on Bitcoin, or production security review.

The RPC page refreshes gateway chain and build observations and labels reported corroboration separately from independent verification. It keeps up to 120 browser-tab observations, exports JSON or CSV with sample limitations, and publishes a versioned source-derived read-only method catalog and compatibility probe. The probe can compare an independently supplied network domain and a second RPC's finalized checkpoint. Failed or invalid chain refreshes clear the current figures while preserving earlier observations in history. The validator page refreshes funded admission with unavailable and stale states. It distributes a read-only Node.js preflight tool and a local checkpoint verifier that compares the node's cryptographic verification result with an independently supplied digest and records bounded evidence. The PQ Shield page provides a loopback-only Node.js client and regtest workflow, local contract and route checks using public fixtures, offline response tests, and a machine-readable OpenAPI contract; it never asks the browser for keys or sends a request to a hosted PQ Shield service.

Deploy the directory with Cloudflare Pages project `bloch-ops`. The custom domain `ops-blochinc.xyz` is active. The root `_headers` file permits read-only browser calls to the published Postern Labs RPC gateway and Bloch Explorer transaction API.
