# Bloch Pay website

Static roadmap site for `blochpay.xyz`, covering Bloch Treasury and Bloch Pay API.

Both product lines are design-stage in the current portfolio. The site describes proposed policy approvals, invoices, finality-aware receipts and reconciliation without claiming live custody, fiat payment rails, credit or regulated payment operations. Delivery depends on a hardened wallet, complete indexing and documented controls.

Preview locally:

```sh
python3 -m http.server 4175 --directory apps/bloch-pay
```

Deploy the directory as a Cloudflare Pages static site.
