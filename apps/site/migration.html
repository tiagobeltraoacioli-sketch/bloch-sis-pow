The sequence

Four phases, in order.

Each one only begins when the one above it has finished.

  1. done

    Proof of work halted

    The chain produced blocks under SHA-256d with merged mining until it halted by consensus rule. It actually stopped, and was snapshotted, at height 39,918.

  2. done

    The chain halted

    Blocks above the terminal height (50,000) are invalid — a consensus rule compiled into every node, not a switch anyone threw. A chain does not stop because it was announced; if late blocks were merely unwanted, miners would keep producing them and the “halt” would be a fork nobody agreed to. Making them invalid is what actually ended the chain.

    Mining revenue ended there. The signed snapshot of every balance, taken at height 39,918, is the canonical carryover record.

  3. done

    The gap

    Balances sat in the snapshot; the explorer kept serving history. That review period is over.

    One consequence stated plainly: once mining stopped, the old chain’s history stopped being evidence — proof-of-work security was bought with ongoing hashrate. That is why the canonical artifact was the signed snapshot, whose digest is embedded in the Genesis-4 genesis block, and not whatever chain had the most work afterwards.

  4. now

    Proof of stake, from the snapshot live

    Genesis-4 has been running since 2026-08-13 21:31:19 UTC. Every Genesis-3 balance crossed as an ordinary liquid balance — 452,726 UTXOs, carried automatically. Carried-over coins can be staked and delegated like any other coin.
