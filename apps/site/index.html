What it is

Three commitments, and what each one costs.

Stated with the trade-off attached, because a protocol page that only lists benefits is marketing.

Signatures

Hybrid, not hedged

ML-DSA-65 and Falcon-1024 both have to verify. Breaking one is not enough.

The cost: up to 4,775 bytes per signature against Bitcoin’s 64, and no hardware wallet implements either scheme.

Privacy

Hash-based shielded pool

Coherence uses SHAKE-256 commitments and STARK proofs — no trusted setup, no elliptic-curve ZK.

The cost: proofs are large, and the pool carries no privacy claim until it is audited.

Consensus

Moving to proof of stake

Slots, epochs, LMD-GHOST, Casper-style finality — with the same post-quantum signatures.

The cost: the validator set starts concentrated, and the rules that reduce that are on a one-year clock.

Migration

Genesis-3 ends. Genesis-4 starts from its snapshot.

These are ordered steps, not a list — each one only begins when the one above it has finished.

  1. now

    Proof of work, running live

    The chain produces blocks under SHA-256d with merged mining. Nothing about it changes until height 50,000.

  2. height 50,000

    The chain halts days away

    Blocks above 50,000 are invalid — it is a consensus rule compiled into every node, not a switch anyone throws. Mining revenue ends here. A signed snapshot of every balance is taken at that height.

  3. the gap

    Months with no chain

    Balances sit in the snapshot; the explorer keeps serving history. This is the plan, not a failure — the time is for review before a chain restarts with different consensus.

  4. genesis-4

    Proof of stake, from the snapshot

    Balances carry across untouched. No claim to file, no contract to interact with, nobody to send anything to. Anyone asking you to migrate tokens is stealing them.

What this chain is not, yet.

Security

Unaudited, low-hashrate

The network is nascent: few nodes, low hashrate, 51%-attackable. Mainnet is a designation, not a security claim.

Supply

Concentrated

Roughly 94% of the carried-over balance belongs to one holder — the founder, who mined it. The numbers are on the supply page, not in a footnote.

Genesis-4

No launch date

The proof-of-stake node is devnet software. There is no Genesis-4 launch date, and anyone quoting one is guessing.
