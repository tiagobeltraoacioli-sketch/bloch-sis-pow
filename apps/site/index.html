What it is

Three commitments, and what each one costs.

Stated with the trade-off attached, because a protocol page that only lists benefits is marketing.

Signatures

Hybrid, not hedged

ML-DSA-65 and Falcon-1024 both have to verify. Breaking one is not enough.

The cost: up to 4,775 bytes per signature against Bitcoin’s 64, and no hardware wallet implements either scheme.

Privacy

Hash-based shielded pool

Coherence uses SHAKE-256 commitments and STARK proofs — no trusted setup, no elliptic-curve ZK.

The cost: proofs are large, and the pool carries no privacy claim until it is audited.

Consensus

Proof of stake, live

Slots, epochs, LMD-GHOST, Casper-style finality — with the same post-quantum signatures. Live since 2026-08-13.

The cost: the validator set starts concentrated, and the rules that reduce that are on a one-year clock.

Migration

Genesis-3 ends. Genesis-4 starts from its snapshot.

These are ordered steps, not a list — each one only begins when the one above it has finished.

  1. done

    Proof of work halted

    The chain produced blocks under SHA-256d with merged mining until it halted by consensus rule. It actually stopped, and was snapshotted, at height 39,918.

  2. done

    Snapshot signed and published

    Blocks above the terminal height are invalid on every node. Mining revenue ended there. The signed snapshot of every balance at height 39,918 is the canonical carryover record.

  3. done

    The gap

    Balances sat in the snapshot while the explorer kept serving history. That review period is over.

  4. now

    Proof of stake, from the snapshot live

    Genesis-4 has been running since 2026-08-13 21:31:19 UTC. Balances carried across untouched — no claim was filed, no contract interacted with, nobody sent anything to anyone. Anyone asking you to migrate tokens today is stealing them.

The full migration plan

Wallet

A wallet that signs with the chain’s own cryptography.

Installable from the browser. The hybrid ML-DSA-65 ‖ Falcon-1024 signing runs in WebAssembly on your device — the same construction the chain verifies, not a classical key with a post-quantum label on it.

What it does

Post-quantum signing, locally

Keys are generated and used in your browser. Node access is read-only, over the public RPC — no node runs in the page and no mining is possible from it.

Installable

A PWA, not an app store

Add it to your home screen and it works offline for everything that does not need the chain. Nothing to approve, nobody to ask.

Unaudited

Public beta — read this part

No third-party security audit has been completed on the wallet or on the chain it talks to. It hardens your setup; it does not make you anonymous, and endpoint traffic analysis remains possible. Do not put in it more than you can lose.

What this chain is not, yet.

Security

Stake, not hashrate — still concentrated

The network is nascent and unaudited. The risk that matters for a proof-of-stake chain is stake concentration, not hashrate: the genesis validator cohort starts concentrated, and the rules that taper it run on a one-year clock. Mainnet is a designation, not a security claim.

Supply

Concentrated

93.94% of the carried-over balance belongs to one holder — the founder, who mined it. The numbers are on the supply page, not in a footnote.

Genesis-4

Live, with most safety upgrades still inert

Genesis-4 mainnet has been live since 2026-08-13 21:31:19 UTC. Several consensus fixes shipped in code ship behind activation-epoch gates that are not yet armed on the live chain — check the current audit status before assuming a named fix is in force.
