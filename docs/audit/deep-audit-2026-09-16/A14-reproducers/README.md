# Annex A14 — reproducers

Test sources and step-by-step plans written by the independent second-lens reviewers (Annex A13 §A13.3). They were **not** run and are **not** wired into any crate's test suite: each `.rs` file targets the crate's existing test API as the reviewer read it and may need adjustment to compile. Only the five second-lens reviews that returned (TX-11, TX-12, INF-01, NET-01, NET-03) produced files.
