# v0.7.0-alpha.1 — Stratum V2 Transport Ready

**Release date:** 2026-04-23  
**Milestone:** Sprint 8 closes. NOISE_NX transport, session state machine, and SetupConnection policy layer are production-ready. SetupConnection wire response (reply frames to the peer) is deferred to v0.8.0.

## What ships in this release

This release delivers a Stratum V2 **pool-side transport** that can:

- Accept TCP connections on a bound port
- Complete a NOISE_NX handshake as Responder (authority keypair + SIGNATURE_NOISE_MESSAGE cert)
- Enforce a configurable per-listener session cap with automatic counter decrement on drop
- Run an encrypted session loop with `SETUP_CONNECTION_TIMEOUT` for the first message and `DEFAULT_IDLE_TIMEOUT` between subsequent reads
- Decrypt, log, and re-encrypt each frame using the `NoiseCodec` returned by the handshake (full round-trip validated end-to-end in unit tests)

The `setup_connection` policy module is complete and independently tested, but the code path that takes a decrypted frame, parses it as a real `SetupConnection` SV2 message, runs `validate()`, and writes back a `SetupConnectionSuccess` or `SetupConnectionError` does **not** ship in this release. See "Deferred to v0.8.0" below.

### Security-relevant decisions

- **Fail-closed on unknown flags** — any bit outside `known_flag_mask` in a `SetupConnection.flags` field is treated as `UnknownFlags` and rejected. The SRI spec says "ignore unknown flags"; we deliberately diverge because a forward-compatible accept opens attack surface for feature-negotiation confusion.
- **Session setup deadline** — `SETUP_CONNECTION_TIMEOUT` (10s) bounds the time between handshake completion and first message. Prevents slow-loris initiators from holding session slots.
- **Idle timeout in live loop** — `DEFAULT_IDLE_TIMEOUT` (10s) caps the gap between consecutive frames once live. Pools typically see share submissions every few seconds; longer silence closes the connection.
- **Authority key material in memory** — the `Responder` drop impl zeroizes its secret state. The authority keypair we load from disk stays in the `Sv2StaticKeypair` struct; callers must ensure the parent process is trusted.

## Deferred to v0.8.0

These items were scoped for Sprint 8 but deferred after scanning the `stratum_core v0.2.1` API surface. They require a focused dive into `codec_sv2 v5.0.0` (generic `WithNoise<B, T>` decoder + external `State` enum) and `common_messages_sv2 v7.0.0` (lifetime-parameterized `SetupConnection<'decoder>` with `Str0255<'decoder>` fields):

- `codec_sv2::StandardNoiseDecoder` framing — solves TCP fragmentation; current loop assumes one SV2 frame per `read` syscall
- Real `SetupConnection` parse from the decrypted plaintext via `binary_sv2::from_bytes`
- `SetupConnectionSuccess` / `SetupConnectionError` response construction and encrypted write back to the peer (replaces the current echo placeholder in `drive_session_io`)
- `main.rs` CLI flag `--stratum-v2` that spawns `stratum_v2::run(...)` alongside the existing Stratum V1 listener
- Integration test: two nodes on localhost exchanging SV2 SetupConnection + Success

## Known limitations

- **Echo placeholder in live loop.** After handshake, the session loop decrypts incoming frames, logs plaintext size, then re-encrypts and echoes the same bytes back. A real SV2 initiator will receive back its own bytes instead of `SetupConnectionSuccess`. This is harmless (initiator will time out or disconnect) but means no actual SV2 role can complete a setup against this build.
- **No TCP frame reassembly.** A single SV2 frame split across multiple `read` syscalls would fail decrypt. Safe on loopback; unsafe across WAN. Fixed by `StandardNoiseDecoder` in v0.8.0.
- **`stratum_v2::run` is not wired into `main.rs`.** The listener exists and is fully tested, but running the binary with `--stratum` still uses Stratum V1 only. Manually invoking `stratum_v2::run` requires custom code.

## Migration notes

None. No breaking changes to public APIs. `Sv2Session.codec` changed type internally from `NoiseCodec` to `Option<NoiseCodec>` for `run()` to `.take()` cleanly, but the only public constructor (`Sv2Session::new`) still accepts a plain `NoiseCodec`.
