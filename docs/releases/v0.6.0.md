# GroundState v0.6.0 — Stratum-ready hard fork

**Status at this tag:** Consensus + protocol code complete.
Main.rs CLI wiring, operator controls, and chain reset are
deferred to v0.6.0-final (this tag is currently v0.6.0-alpha2).

## Summary

Two coordinated consensus changes that together make SHA-256d ASIC
mining viable on GroundState while preserving BlockDAG semantics:

1. **Sprint AA.0** — `pow_hash()` now hashes a derived 80-byte
   Bitcoin-compatible `MiningHeader`, not the variable-length full
   `BlockHeader`. See `legacy/architecture/mining-header.md`.

2. **Sprint AA.1** — Full stratum V1 JSON-RPC server scaffolded
   under `src/stratum/`. Protocol + session + job template + share
   validation complete. CLI wiring pending in v0.6.0-final.

A third change landed incidentally:

3. **`Transaction::txid` switched from bincode to Bitcoin-format
   bytes.** Required so external miners (computing txid as
   SHA-256d of `coinb1 || en1 || en2 || coinb2`) and the node
   agree on coinbase txids, which in turn determines the merkle
   root. Consensus-breaking; piggybacks on AA.0's hard fork.

## Breaking changes (hard fork from v0.5.x)

**Every block hash on an existing chain is different under v0.6.0**
because:

- `pow_hash` now hashes 80 bytes (MiningHeader) instead of
  serialized full BlockHeader
- `txid` now hashes Bitcoin-format transaction bytes instead of
  bincode

Nodes running v0.5.13 and v0.6.0 cannot speak to each other.
Activation requires a new genesis block and a fresh data-dir on
every node.

## New architecture: MiningHeader

```rust
pub struct MiningHeader {
    pub version:     u32,      //  4 bytes
    pub prev_hash:   [u8; 32], // 32 bytes (parents_commitment)
    pub merkle_root: [u8; 32], // 32 bytes
    pub timestamp:   u32,      //  4 bytes
    pub bits:        u32,      //  4 bytes
    pub nonce:       u32,      //  4 bytes
    // Total: 80 bytes, exact Bitcoin layout
}
```

`BlockHeader::to_mining_header()` derives it deterministically:

- `prev_hash = parents_commitment(&parents)` — merkle-style fold
  of sorted parent hashes, order-independent
- `timestamp` = low 32 bits of the u64 on-chain timestamp
  (acceptable until year 2106)
- `nonce` = low 32 bits of the u64 on-chain nonce (miner explores
  via stratum extranonce for additional entropy)

`BlockHeader::pow_hash()` delegates to `MiningHeader::pow_hash()`,
which is `SHA256d` of the 80-byte layout.

`BlockHeader::dag_hash()` is **unchanged** — still SHA3-256 of the
full serialized header. Used for DAG indexing internally.

## Stratum V1 server (scaffolded, not yet CLI-enabled)

Module `src/stratum/` contains:

- `mod.rs` — TCP listener, session registry with configurable cap,
  accept-loop, broadcast channel plumbing for TipChanged events
- `protocol.rs` — newline-delimited JSON-RPC framing, Bitcoin-
  standard error codes (20/21/22/23/24/25)
- `session.rs` — per-connection state machine (Fresh → Subscribed
  → Authorized), unique 4-byte extranonce1, auth/idle timeouts,
  submission rate limiter, template LRU (16 slots), duplicate-share
  cache
- `jobs.rs` — `Template` struct with `build()` that splits coinbase
  at the extranonce injection point, `compute_merkle_branch` +
  `walk_merkle_branch` (Bitcoin sibling path), `to_notify_params`
  rendering
- `submit.rs` — full share validation pipeline: params parse,
  dedup, template lookup, coinbase reconstruction, merkle walk,
  PoW check against target, Block assembly, `accept_block`
  callback invocation

## What's in v0.6.0-alpha2 (this tag)

Code is compilable and every unit test green. Stratum module exists
but is **not yet instantiated by main.rs** — there are no CLI flags,
no tokio::spawn of the server, no tip-change broadcast wiring.

A node built from this tag behaves exactly like v0.5.13 at runtime
for mining purposes, but with the new consensus rules baked in.

Estimate: 800-1000 lines additional across main.rs + stratum::run

## Rationale

The pre-v0.6.0 design mined successfully on CPUs but was invisible
to every SHA-256d ASIC on the planet — their silicon expects
Bitcoin's exact 80-byte layout. AA.0 threads the needle by
preserving BlockDAG parents (variable count) in the `BlockHeader`
for DAG operations, but projecting to 80 bytes for the actual PoW.

Stratum V1 is the industry-standard protocol for miner↔pool
communication. Supporting it out-of-the-box means every existing
cgminer, BFGMiner, Braiins OS, Antminer firmware, and software
miner in the world can point at a GroundState node without
modification.

Combined, these changes open the door to real mining hashrate
for GroundState. Whether that arrives remains market-dependent,
but the technical blocker is being removed.
